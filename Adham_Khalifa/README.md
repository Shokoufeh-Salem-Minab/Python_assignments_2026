# Homework 7 - Sales Data Analysis

Files:
- sales.csv: 20 sample sales records.
- main.py: Python, NumPy, Pandas and Matplotlib solution.
- updated_sales.csv: dataset with Total_Sales, sorted descending.
- analysis.txt: answers and interpretation.
- bar_chart.png, pie_chart.png, histogram.png: the three charts.

## Run in Anaconda / Spyder
1. Extract this folder.
2. Open Anaconda Navigator and launch Spyder.
3. Open main.py.
4. Set Spyder's working directory to this folder.
5. Press F5.

If packages are missing, run in Anaconda Prompt:
conda install numpy pandas matplotlib
