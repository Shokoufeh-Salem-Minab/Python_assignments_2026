HOMEWORK 6 - STUDENT PERFORMANCE ANALYSIS

Files:
procedural.py       Procedural programming
oop.py              Object-oriented programming
functional.py       Functional programming
numpy_analysis.py   NumPy calculations
pandas_analysis.py  Pandas report and CSV export
student_report.csv  Generated report

On Mac, open Terminal in this folder and run:
python3 -m pip install numpy pandas

Then run:
python3 procedural.py
python3 oop.py
python3 functional.py
python3 numpy_analysis.py
python3 pandas_analysis.py

The Pandas program creates student_report.csv.

Reflection:
Procedural programming uses functions and step-by-step instructions. It is
simple for small programs, but data and functions are separate.
OOP puts data and methods together in classes. It organizes larger programs,
but can require more code.
Functional programming transforms data with functions such as map, filter,
reduce, and sorted. It can be concise, but may be less familiar.
NumPy is useful for fast mathematical calculations with arrays.
Pandas is useful for table data, filtering, sorting, grouping, and CSV files.
